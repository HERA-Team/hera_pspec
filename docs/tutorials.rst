*********
Tutorials
*********

The following Jupyter notebooks walk through the main features of
``hera_pspec``, from estimating a power spectrum out of a visibility dataset to
forming pseudo-Stokes spectra, propagating errors, and plotting results. They
are rendered here from their saved outputs; the source notebooks live in
``docs/examples/`` in the `GitHub repository
<https://github.com/HERA-Team/hera_pspec/tree/main/docs/examples>`_ and can be
run locally.
